# JobRadar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a containerized service that polls job boards, scores each new vacancy against the owner's CV using a swappable LLM provider, stores results in Postgres, and pushes matches to Telegram.

**Architecture:** A six-stage pipeline (fetch → dedupe → hard-filter → classify → store → notify) executed on a 30-minute schedule by a `worker` container. Source adapters and LLM providers sit behind narrow interfaces so new boards and new models are additive. A `web` container serves a read-only dashboard from the same image.

**Tech Stack:** Node 22, TypeScript (ESM), Postgres 17, Drizzle ORM + `postgres.js`, `undici`, `cheerio`, `@anthropic-ai/sdk`, `hono`, `node-cron`, `zod`, `vitest`, Docker Compose.

## Global Constraints

- Node 22, TypeScript strict mode, ESM only (`"type": "module"`, `moduleResolution: "bundler"`). No CommonJS `require`.
- `__dirname` does not exist in ESM. Derive paths with `fileURLToPath(import.meta.url)` or read from `/config`.
- Default classifier model is exactly `claude-haiku-4-5`.
- The Anthropic provider MUST NOT send `output_config.effort` (errors on Haiku 4.5), MUST NOT send `thinking`, and MUST NOT set `cache_control` (the ~1600-token prefix is below Haiku 4.5's 4096-token cache minimum, so a marker is a silent no-op).
- Verdict bands: total ≥ 75 → `STRONG`; 50–74 → `MAYBE`; < 50 → `NO`. Notify threshold default 50.
- Rubric weights: coreStack 35, seniority 20, domain 15, logistics 20, growth 10. Total is computed in code, never by the model.
- `scores` is append-only. Never `UPDATE` a score row; re-scoring inserts a new row carrying `provider_id` and `rubric_version`.
- Runtime config files (`cv.md`, `profile.yaml`, `rubric.md`, `sources.yaml`) are read from `/config` at runtime, mounted read-only. They are never bundled into the image.
- Secrets come from env only: `ANTHROPIC_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `DATABASE_URL`. Never commit `.env`.
- Every task ends with a commit. Conventional Commit prefixes (`feat:`, `test:`, `chore:`, `fix:`).

```ts
import { readFileSync, existsSync } from 'node:fs';
import { join } from 'node:path';
import { parse as parseYaml } from 'yaml';
import { ProfileSchema, SourcesSchema, type AppConfig, type Rubric } from './schema.js';

function read(dir: string, name: string): string {
  const path = join(dir, name);
  if (!existsSync(path)) {
    throw new Error(`Missing required config file: ${name} (looked in ${dir})`);
  }
  return readFileSync(path, 'utf8');
}

function parseRubric(text: string): Rubric {
  const match = /^version:\s*(\S+)\s*$/m.exec(text);
  if (!match?.[1]) {
    throw new Error('rubric.md must start with a "version: <id>" header line');
  }
  return { version: match[1], body: text };
}

export function loadConfig(dir: string): AppConfig {
  return {
    cv: read(dir, 'cv.md'),
    rubric: parseRubric(read(dir, 'rubric.md')),
    profile: ProfileSchema.parse(parseYaml(read(dir, 'profile.yaml'))),
    sources: SourcesSchema.parse(parseYaml(read(dir, 'sources.yaml'))),
  };
}
```

```ts
import * as cheerio from 'cheerio';
import type { FetchFn, JobSource, RawPosting } from '../types.js';

export interface AtsEntry {
  board: 'greenhouse' | 'lever' | 'ashby';
  slug: string;
}

const ENDPOINTS: Record<AtsEntry['board'], (slug: string) => string> = {
  greenhouse: (s) => `https://boards-api.greenhouse.io/v1/boards/${s}/jobs?content=true`,
  lever: (s) => `https://api.lever.co/v0/postings/${s}?mode=json`,
  ashby: (s) => `https://api.ashbyhq.com/posting-api/job-board/${s}`,
};

export function htmlToText(html: string): string {
  return cheerio.load(html).root().text().replace(/\s+/g, ' ').trim();
}

function mapGreenhouse(slug: string, body: any): RawPosting[] {
  return (body.jobs ?? []).map((j: any) => ({
    id: `greenhouse:${slug}:${j.id}`,
    source: 'greenhouse',
    externalId: String(j.id),
    url: j.absolute_url,
    title: j.title,
    company: slug,
    location: j.location?.name ?? null,
    employmentType: null,
    description: htmlToText(j.content ?? ''),
    raw: j,
  }));
}

function mapLever(slug: string, body: any): RawPosting[] {
  return (body ?? []).map((j: any) => ({
    id: `lever:${slug}:${j.id}`,
    source: 'lever',
    externalId: String(j.id),
    url: j.hostedUrl,
    title: j.text,
    company: slug,
    location: j.categories?.location ?? null,
    employmentType: j.categories?.commitment ?? null,
    description: (j.descriptionPlain ?? '').replace(/\s+/g, ' ').trim(),
    raw: j,
  }));
}

function mapAshby(slug: string, body: any): RawPosting[] {
  return (body.jobs ?? []).map((j: any) => ({
    id: `ashby:${slug}:${j.id}`,
    source: 'ashby',
    externalId: String(j.id),
    url: j.jobUrl,
    title: j.title,
    company: slug,
    location: j.location ?? null,
    employmentType: j.employmentType ?? null,
    description: (j.descriptionPlain ?? '').replace(/\s+/g, ' ').trim(),
    raw: j,
  }));
}
```

```ts
import type { RawPosting } from './types.js';
import type { Profile } from './config/schema.js';

export type FilterResult = { passed: true } | { passed: false; rule: string };

const SALARY_RE = /\$\s?(\d[\d,\s]{2,})/g;

export function statedSalaryUsd(text: string): number | null {
  const values: number[] = [];
  for (const m of text.matchAll(SALARY_RE)) {
    const n = Number(m[1]!.replace(/[,\s]/g, ''));
    if (Number.isFinite(n) && n > 0) values.push(n);
  }
  return values.length ? Math.max(...values) : null;
}

export function applyHardFilters(posting: RawPosting, profile: Profile): FilterResult {
  const location = (posting.location ?? '').toLowerCase();
  if (profile.excludedLocations.some((x) => location.includes(x.toLowerCase()))) {
    return { passed: false, rule: 'location' };
  }

  if (profile.allowedEmploymentTypes.length > 0 && posting.employmentType) {
    const type = posting.employmentType.toLowerCase();
    const ok = profile.allowedEmploymentTypes.some((x) => type.includes(x.toLowerCase()));
    if (!ok) return { passed: false, rule: 'employment-type' };
  }

  if (profile.minSalaryUsd !== null) {
    const stated = statedSalaryUsd(posting.description);
    if (stated !== null && stated < profile.minSalaryUsd) {
      return { passed: false, rule: 'salary' };
    }
  }

  return { passed: true };
}
```

```ts
export const WEIGHTS = {
  coreStack: 35,
  seniority: 20,
  domain: 15,
  logistics: 20,
  growth: 10,

export function weightedTotal(s: SubScores): number {
```

```ts
import type { FitVerdict, RawPosting } from '../types.js';
import type { Profile, Rubric } from '../config/schema.js';
import type { LLMProvider } from './providers/types.js';
import { RawVerdictSchema, VERDICT_JSON_SCHEMA, type RawVerdict } from './schema.js';
import { buildPrompt } from './prompt.js';
import { toVerdict, weightedTotal } from './rubric.js';

export interface ClassifyArgs {
  provider: LLMProvider;
  cv: string;
  profile: Profile;
  rubric: Rubric;
  posting: RawPosting;
}

export function extractJson(raw: string): unknown {
  const fenced = /```(?:json)?\s*([\s\S]*?)```/.exec(raw);
  const candidate = fenced?.[1] ?? raw;
  const start = candidate.indexOf('{');
  const end = candidate.lastIndexOf('}');
  if (start === -1 || end <= start) throw new Error('no JSON object found in response');
  return JSON.parse(candidate.slice(start, end + 1));
}

function parse(raw: string): RawVerdict {
  return RawVerdictSchema.parse(extractJson(raw));
}

export async function classify(args: ClassifyArgs): Promise<FitVerdict> {
  const { provider, rubric } = args;
  const { system, user } = buildPrompt(args);

  let parsed: RawVerdict;
  try {
    const first = await provider.complete({ system, user, schema: VERDICT_JSON_SCHEMA });
    parsed = parse(first.raw);
  } catch (firstError) {
    const detail = firstError instanceof Error ? firstError.message : String(firstError);
    const repairUser = [
      user,
      '',
      'Your previous response was invalid and could not be parsed.',
      `Error: ${detail}`,
      'Reply with only the JSON object required by the schema. No prose, no code fences.',
    ].join('\n');

    try {
      const second = await provider.complete({ system, user: repairUser, schema: VERDICT_JSON_SCHEMA });
      parsed = parse(second.raw);
    } catch (secondError) {
      const d2 = secondError instanceof Error ? secondError.message : String(secondError);
      throw new Error(`Classifier response failed schema validation twice (${provider.id}): ${d2}`);
    }
  }

  const total = weightedTotal(parsed.subscores);
  return {
    total,
    verdict: toVerdict(total),
    subscores: parsed.subscores,
    reasoning: parsed.summary,
    providerId: provider.id,
    rubricVersion: rubric.version,
  };
}
```

```ts
import type { CompletionRequest, LLMProvider } from './types.js';

export const DEFAULT_ANTHROPIC_MODEL = 'claude-haiku-4-5';

export interface MessagesClient {
  messages: { create(params: Record<string, unknown>): Promise<any> };
}

export interface AnthropicProviderOptions {
  apiKey: string;
  model?: string;
  maxTokens?: number;
  client?: MessagesClient;
}

export function createAnthropicProvider(opts: AnthropicProviderOptions): LLMProvider {
  const model = opts.model ?? DEFAULT_ANTHROPIC_MODEL;
  const client: MessagesClient = opts.client ?? new Anthropic({ apiKey: opts.apiKey });

  return {
    id: `anthropic:${model}`,
    async complete(req: CompletionRequest) {
      // Deliberately omitted for Haiku 4.5: output_config.effort (errors),
      // thinking (unnecessary), and cache_control (prefix is under the
      // 4096-token cache minimum, so a marker is a silent no-op).
      const res = await client.messages.create({
        model,
        max_tokens: opts.maxTokens ?? 1024,
        system: req.system,
        messages: [{ role: 'user', content: req.user }],
        output_config: { format: { type: 'json_schema', schema: req.schema } },
      });

      const block = (res.content ?? []).find((b: any) => b.type === 'text');
      if (!block) throw new Error('Anthropic response contained no text block');

      const usage = res.usage
        ? { inputTokens: res.usage.input_tokens ?? 0, outputTokens: res.usage.output_tokens ?? 0 }
        : undefined;

      return { raw: block.text as string, usage };
    },
  };
}
```

```ts
import type { CompletionRequest, LLMProvider } from './types.js';

export interface OpenAiCompatOptions {
  baseUrl: string;
  model: string;
  apiKey?: string;
  /** Set true for servers that honour response_format json_schema (vLLM, recent Ollama). */
  jsonSchemaSupport?: boolean;
  maxTokens?: number;
  fetchFn?: typeof fetch;
}

export function createOpenAiCompatProvider(opts: OpenAiCompatOptions): LLMProvider {
  const base = opts.baseUrl.replace(/\/+$/, '');
  const doFetch = opts.fetchFn ?? fetch;

  return {
    id: `openai-compat:${opts.model}`,
    async complete(req: CompletionRequest) {
      const system = opts.jsonSchemaSupport
        ? req.system
        : `${req.system}\n\nReturn JSON conforming exactly to this schema:\n${JSON.stringify(req.schema)}`;

      const body: Record<string, unknown> = {
        model: opts.model,
        max_tokens: opts.maxTokens ?? 1024,
        messages: [
          { role: 'system', content: system },
          { role: 'user', content: req.user },
        ],
      };

      if (opts.jsonSchemaSupport) {
        body.response_format = {
          type: 'json_schema',
          json_schema: { name: 'fit_verdict', schema: req.schema, strict: true },
        };
      }

      const res = await doFetch(`${base}/chat/completions`, {
        method: 'POST',
        headers: {
          'content-type': 'application/json',
          ...(opts.apiKey ? { authorization: `Bearer ${opts.apiKey}` } : {}),
        },
        body: JSON.stringify(body),
      });

      if (!res.ok) {
        throw new Error(`${this.id} returned HTTP ${res.status}: ${await res.text()}`);
      }

      const json: any = await res.json();
      const raw = json.choices?.[0]?.message?.content;
      if (typeof raw !== 'string') throw new Error(`${this.id} returned no message content`);

      const usage = json.usage
        ? { inputTokens: json.usage.prompt_tokens ?? 0, outputTokens: json.usage.completion_tokens ?? 0 }
        : undefined;

      return { raw, usage };
    },
  };
}
```

```ts
import { and, desc, eq, gte, isNotNull, sql } from 'drizzle-orm';
import type { Database } from './client.js';
import { notifications, postings, runLog, scores } from './schema.js';
import type { FitVerdict, RawPosting } from '../types.js';

export interface PendingNotification {
  scoreId: number;
  postingId: string;
  title: string;
  company: string;
  url: string;
  location: string | null;
  total: number;
  verdict: 'STRONG' | 'MAYBE' | 'NO';
  reasoning: string;
}

export async function upsertPosting(db: Database, p: RawPosting): Promise<{ isNew: boolean }> {
  const rows = await db
    .insert(postings)
    .values({
      id: p.id, source: p.source, url: p.url, title: p.title, company: p.company,
      location: p.location, employmentType: p.employmentType,
      description: p.description, raw: p.raw as object,
    })
    .onConflictDoUpdate({ target: postings.id, set: { lastSeen: new Date() } })
    .returning({ firstSeen: postings.firstSeen, lastSeen: postings.lastSeen });

  const row = rows[0];
  if (!row) throw new Error(`upsertPosting returned no row for ${p.id}`);
  return { isNew: row.firstSeen.getTime() === row.lastSeen.getTime() };
}

export async function insertScore(db: Database, postingId: string, v: FitVerdict): Promise<number> {
  const rows = await db.insert(scores).values({
    postingId,
    providerId: v.providerId,
    rubricVersion: v.rubricVersion,
    total: v.total,
    verdict: v.verdict,
    subscores: v.subscores,
    reasoning: v.reasoning,
  }).returning({ id: scores.id });

  const row = rows[0];
  if (!row) throw new Error(`insertScore returned no row for ${postingId}`);
  return row.id;
}

export async function pendingNotifications(
  db: Database, minTotal: number, channel: string,
): Promise<PendingNotification[]> {
  const sent = db
    .select({ scoreId: notifications.scoreId })
    .from(notifications)
    .where(and(eq(notifications.channel, channel), isNotNull(notifications.sentAt)));

  return db
    .select({
      scoreId: scores.id,
      postingId: postings.id,
      title: postings.title,
      company: postings.company,
      url: postings.url,
      location: postings.location,
      total: scores.total,
      verdict: scores.verdict,
      reasoning: scores.reasoning,
    })
    .from(scores)
    .innerJoin(postings, eq(postings.id, scores.postingId))
    .where(and(gte(scores.total, minTotal), sql`${scores.id} NOT IN ${sent}`))
    .orderBy(desc(scores.total));
}

export async function recordNotification(
  db: Database, scoreId: number, channel: string, error?: string,
): Promise<void> {
  await db.insert(notifications).values({
    scoreId, channel,
    sentAt: error ? null : new Date(),
    error: error ?? null,
  });
}

export async function logRun(
  db: Database, source: string, status: 'ok' | 'error', postingsSeen: number, error?: string,
): Promise<void> {
  await db.insert(runLog).values({ source, status, postingsSeen, error: error ?? null });
}
```

```ts
import type { PendingNotification } from '../db/repo.js';
import type { Notifier } from './types.js';

export interface TelegramOptions {
  botToken: string;
  chatId: string;
  fetchFn?: typeof fetch;
}

export function escapeHtml(s: string): string {
  return s.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;');
}

export function formatMessage(item: PendingNotification): string {
  const e = escapeHtml;
  return [
    `<b>${item.verdict} · ${item.total}</b>`,
    `<b>${e(item.title)}</b> — ${e(item.company)}`,
    item.location ? e(item.location) : null,
    '',
    e(item.reasoning),
    '',
    item.url,
  ].filter((l) => l !== null).join('\n');
}

export function createTelegramNotifier(opts: TelegramOptions): Notifier {
  const doFetch = opts.fetchFn ?? fetch;

  return {
    channel: 'telegram',
    async send(item: PendingNotification): Promise<void> {
      const res = await doFetch(`https://api.telegram.org/bot${opts.botToken}/sendMessage`, {
        method: 'POST',
        headers: { 'content-type': 'application/json' },
        body: JSON.stringify({
          chat_id: opts.chatId,
          text: formatMessage(item),
          parse_mode: 'HTML',
          disable_web_page_preview: false,
        }),
      });

      if (!res.ok) throw new Error(`Telegram HTTP ${res.status}: ${await res.text()}`);
      const json: any = await res.json();
      if (json.ok !== true) throw new Error(`Telegram error: ${json.description ?? 'unknown'}`);
    },
  };
}
```

```ts
import type { FitVerdict, JobSource, RawPosting } from './types.js';
import type { Profile, Rubric } from './config/schema.js';
import type { LLMProvider } from './classifier/providers/types.js';
import type { Notifier } from './notify/types.js';
import type { PendingNotification } from './db/repo.js';
import { applyHardFilters } from './filters.js';
import { classify } from './classifier/classify.js';

export interface PipelineRepo {
  upsertPosting(p: RawPosting): Promise<{ isNew: boolean }>;
  insertScore(postingId: string, v: FitVerdict): Promise<number>;
  pendingNotifications(minTotal: number, channel: string): Promise<PendingNotification[]>;
  recordNotification(scoreId: number, channel: string, error?: string): Promise<void>;
  logRun(source: string, status: 'ok' | 'error', postingsSeen: number, error?: string): Promise<void>;
}

export interface PipelineDeps {
  sources: JobSource[];
  provider: LLMProvider;
  notifier: Notifier;
  repo: PipelineRepo;
  cv: string;
  profile: Profile;
  rubric: Rubric;
  notifyThreshold: number;
  log?: (msg: string) => void;
}

export interface RunSummary {
  fetched: number;
  skippedDuplicate: number;
  hardFiltered: number;
  classified: number;
  classifyErrors: number;
  notified: number;
  notifyErrors: number;
  sourceErrors: number;
}

const ZERO_SUBSCORES = {
  coreStack: { score: 0, note: 'hard filter' },
  seniority: { score: 0, note: 'hard filter' },
  domain: { score: 0, note: 'hard filter' },
  logistics: { score: 0, note: 'hard filter' },
  growth: { score: 0, note: 'hard filter' },
};

export async function runPipeline(deps: PipelineDeps): Promise<RunSummary> {
  const log = deps.log ?? ((m: string) => console.log(m));
  const s: RunSummary = {
    fetched: 0, skippedDuplicate: 0, hardFiltered: 0, classified: 0,
    classifyErrors: 0, notified: 0, notifyErrors: 0, sourceErrors: 0,
  };

  for (const source of deps.sources) {
    let postings: RawPosting[];
    try {
      postings = await source.listPostings();
      await deps.repo.logRun(source.id, 'ok', postings.length);
    } catch (err) {
      s.sourceErrors += 1;
      const msg = err instanceof Error ? err.message : String(err);
      log(`source ${source.id} failed: ${msg}`);
      await deps.repo.logRun(source.id, 'error', 0, msg);
      continue;
    }

    for (const posting of postings) {
      s.fetched += 1;

      const { isNew } = await deps.repo.upsertPosting(posting);
      if (!isNew) { s.skippedDuplicate += 1; continue; }

      const filter = applyHardFilters(posting, deps.profile);
      if (!filter.passed) {
        s.hardFiltered += 1;
        await deps.repo.insertScore(posting.id, {
          total: 0, verdict: 'NO', subscores: ZERO_SUBSCORES,
          reasoning: `hard-filter:${filter.rule}`,
          providerId: 'hard-filter', rubricVersion: deps.rubric.version,
        });
        continue;
      }

      try {
        const verdict = await classify({
          provider: deps.provider, cv: deps.cv, profile: deps.profile,
          rubric: deps.rubric, posting,
        });
        await deps.repo.insertScore(posting.id, verdict);
        s.classified += 1;
      } catch (err) {
        s.classifyErrors += 1;
        log(`classify failed for ${posting.id}: ${err instanceof Error ? err.message : String(err)}`);
      }
    }
  }

  const pending = await deps.repo.pendingNotifications(deps.notifyThreshold, deps.notifier.channel);
  for (const item of pending) {
    try {
      await deps.notifier.send(item);
      await deps.repo.recordNotification(item.scoreId, deps.notifier.channel);
      s.notified += 1;
    } catch (err) {
      s.notifyErrors += 1;
      const msg = err instanceof Error ? err.message : String(err);
      log(`notify failed for score ${item.scoreId}: ${msg}`);
      await deps.repo.recordNotification(item.scoreId, deps.notifier.channel, msg);
    }
  }

  return s;
}
```

```ts
export function selectProvider(env: NodeJS.ProcessEnv): LLMProvider {
  if (env.LLM_BASE_URL) {
    return createOpenAiCompatProvider({
      baseUrl: env.LLM_BASE_URL,
      model: env.LLM_MODEL ?? 'llama3.1',

function require_(env: NodeJS.ProcessEnv, key: string): string {

    logRun: (src, st, n, err) => repoFns.logRun(db, src, st, n, err),

    profile: cfg.profile,
```

```ts
import cron from 'node-cron';
import { buildDeps } from './app.js';
import { runPipeline } from './pipeline.js';

const schedule = process.env.CRON_SCHEDULE ?? '*/30 * * * *';
const { deps, close } = await buildDeps(process.env);

let running = false;

async function tick(): Promise<void> {
  if (running) {
    console.log(JSON.stringify({ event: 'run.skipped', reason: 'previous run still active' }));
    return;
  }
  running = true;
  try {
    const summary = await runPipeline(deps);
    console.log(JSON.stringify({ event: 'run.complete', ...summary }));
  } catch (err) {
    // A thrown pipeline must never kill the scheduler.
    console.error(JSON.stringify({
      event: 'run.failed',
      error: err instanceof Error ? err.message : String(err),
    }));
  } finally {
    running = false;
  }
}

const task = cron.schedule(schedule, tick);
console.log(JSON.stringify({ event: 'worker.started', schedule }));
await tick();

for (const signal of ['SIGTERM', 'SIGINT'] as const) {
  process.on(signal, async () => {
    console.log(JSON.stringify({ event: 'worker.stopping', signal }));
    await task.stop();
    await close();
    process.exit(0);
  });
}
```

```ts
import { Hono } from 'hono';
import { serve } from '@hono/node-server';
import { desc, eq, sql } from 'drizzle-orm';
import type { Database } from './db/client.js';
import { postings, runLog, scores } from './db/schema.js';
import { escapeHtml } from './notify/telegram.js';
import type { Verdict } from './types.js';

export interface DashboardRow {
  postingId: string;
  title: string;
  company: string;
  url: string;
  source: string;
  location: string | null;
  total: number;
  verdict: Verdict;
  reasoning: string;
  providerId: string;
  scoredAt: Date;
}

export interface HealthRow {
  source: string;
  status: string;
  ranAt: Date;
  error: string | null;
}

export async function latestScores(db: Database): Promise<DashboardRow[]> {
  const latest = db.$with('latest').as(
    db.select({
      postingId: scores.postingId,
      maxId: sql<number>`max(${scores.id})`.as('max_id'),
    }).from(scores).groupBy(scores.postingId),
  );

  return db.with(latest).select({
    postingId: postings.id,
    title: postings.title,
    company: postings.company,
    url: postings.url,
    source: postings.source,
    location: postings.location,
    total: scores.total,
    verdict: scores.verdict,
    reasoning: scores.reasoning,
    providerId: scores.providerId,
    scoredAt: scores.scoredAt,
  })
    .from(latest)
    .innerJoin(scores, eq(scores.id, latest.maxId))
    .innerJoin(postings, eq(postings.id, scores.postingId))
    .orderBy(desc(scores.total));
}

export async function sourceHealth(db: Database): Promise<HealthRow[]> {
  return db.select({
    source: runLog.source,
    status: runLog.status,
    ranAt: runLog.ranAt,
    error: runLog.error,
  }).from(runLog).orderBy(desc(runLog.ranAt)).limit(20);
}

const STYLE = `
body{font:14px/1.5 system-ui,sans-serif;margin:2rem;max-width:1100px}
table{border-collapse:collapse;width:100%}
th,td{border-bottom:1px solid #ddd;padding:.4rem .6rem;text-align:left;vertical-align:top}
.STRONG{background:#e6f7ea}.MAYBE{background:#fff8e1}.near-miss{background:#fdecec}
.total{font-weight:700}
.health{margin-top:2rem;font-size:13px;color:#555}
`;

export function renderPage(rows: DashboardRow[], health: HealthRow[]): string {
  const body = rows.length === 0
    ? '<p>No postings scored yet.</p>'
    : `<table><thead><tr>
        <th>Score</th><th>Verdict</th><th>Title</th><th>Company</th>
        <th>Source</th><th>Location</th><th>Why</th>
      </tr></thead><tbody>${rows.map((r) => {
        const cls = r.verdict === 'NO' && r.total >= 40 ? 'near-miss' : r.verdict;
        return `<tr class="${cls}">
          <td class="total">${r.total}</td>
          <td>${r.verdict}</td>
          <td><a href="${escapeHtml(r.url)}">${escapeHtml(r.title)}</a></td>
          <td>${escapeHtml(r.company)}</td>
          <td>${escapeHtml(r.source)}</td>
          <td>${escapeHtml(r.location ?? '')}</td>
          <td>${escapeHtml(r.reasoning)}</td>
        </tr>`;
      }).join('')}</tbody></table>`;

  const healthHtml = health.length === 0 ? '' : `<div class="health"><h2>Source health</h2><ul>${
    health.map((h) => `<li>${escapeHtml(h.source)} — ${escapeHtml(h.status)}${
      h.error ? `: ${escapeHtml(h.error)}` : ''
    } (${h.ranAt.toISOString()})</li>`).join('')
  }</ul></div>`;

  return `<!doctype html><html><head><meta charset="utf-8">
<title>JobRadar</title><style>${STYLE}</style></head>
<body><h1>JobRadar</h1>${body}${healthHtml}</body></html>`;
}

export function createApp(
  db: Database,
  fetchRows: (db: Database) => Promise<DashboardRow[]> = latestScores,
  fetchHealth: (db: Database) => Promise<HealthRow[]> = sourceHealth,
): Hono {
  const app = new Hono();
  app.get('/', async (c) => c.html(renderPage(await fetchRows(db), await fetchHealth(db))));
  app.get('/healthz', (c) => c.text('ok'));
  return app;
}

if (process.env.NODE_ENV !== 'test' && import.meta.url === `file://${process.argv[1]}`) {

  if (!url) throw new Error('Missing required environment variable: DATABASE_URL');
  const port = Number(process.env.PORT ?? 8080);
  serve({ fetch: createApp(createDb(url)).fetch, port });
  console.log(JSON.stringify({ event: 'web.started', port }));
}
```

````markdown
# JobRadar

Polls job boards, scores each new vacancy against your CV with an LLM, and
pushes matches to Telegram.

## Quick start

```bash
cp .env.example .env && $EDITOR .env      # API key, Telegram bot token + chat id
$EDITOR config/cv.md                       # your CV, in prose
$EDITOR config/profile.yaml                # hard constraints
$EDITOR config/sources.yaml                # boards to watch
docker compose up -d --build
open http://localhost:8080
```

The first run backfills every currently-listed vacancy — expect roughly ten
times a normal run's cost, once.

## Commands

| Command | Purpose |
|---|---|
| `docker compose up -d` | Start db, apply migrations, run worker + dashboard |
| `docker compose run --rm worker node dist/once.js` | Single pipeline run, then exit |
| `docker compose logs -f worker` | Follow scheduled runs |
| `docker compose --profile dev up worker-dev` | Live-reload development |
| `npm test` | Run the test suite on the host (no containers needed) |

## Switching to a local model

Set these in `.env` instead of `ANTHROPIC_API_KEY`:

```
LLM_BASE_URL=http://host.docker.internal:11434/v1
LLM_MODEL=qwen3:14b
LLM_JSON_SCHEMA=true
```

Scores from different models are not comparable — every score row records the
provider that produced it, and re-running adds rows rather than overwriting.

## Tuning the rubric

Edit `config/rubric.md`, bump its `version:` header, then
`docker compose restart worker`. Old scores keep their old version so history
stays interpretable. Watch the near-miss band (scores 40–49) on the dashboard —
a cluster of good vacancies there means the rubric needs adjustment.
````
